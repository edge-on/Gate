What happened

The request reached your server, but nothing came back

EdgeOn's edge node accepted the connection and forwarded your request to the origin server. The origin did not send a response within the configured timeout, so the request was closed.

What you can do

Check that your origin is accepting connections

This usually resolves on its own within a few minutes. If it persists, confirm your server is running and reachable, and that it isn't blocking requests from EdgeOn's edge IP range.
