What is SNI?

Server Name Indication is a TLS extension that carries the hostname you want to reach inside the very first handshake message — before any HTTP header exists. Because a single EdgeOn edge IP serves thousands of domains, SNI is what lets the node present the right certificate and forward traffic to the right origin.

Why this happened

The ClientHello carried no hostname

EdgeOn received your encrypted connection but found no server_name extension in the handshake. That happens when a client dials the IP address directly, uses a legacy TLS stack, or crafts a raw handshake without setting the host.

How to fix it

Send a hostname with your request

  1. Connect to your domain name, not the raw IP address.
  2. Make sure the client speaks TLS 1.2+ with SNI enabled.
  3. With curl, use --resolve host:443:IP instead of the bare IP.
  4. With OpenSSL, add -servername your-domain.com.
  5. Confirm DNS for the hostname points at EdgeOn.
